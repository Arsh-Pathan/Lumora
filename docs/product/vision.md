# LUMORA — Product Vision & Goals

LUMORA is a professional, low-latency projection mapping and live show control software built for event production, visual artists, stage designers, festival VJs, architectural mapping, stage plays, weddings, and installations.

## Core Pillars

1. **Rock-Solid Stability for Live Shows:** Zero crashes during live performances. Emergency blackout and test pattern fallbacks.
2. **Intuitive & Rapid Workflow:** Simple Mode for immediate 5-minute setup; Advanced Mode for deep GPU warping, masks, effects, and output routing.
3. **Decoupled GPU Engine:** 60 FPS frame-rate stability isolated from UI processing.
4. **Self-Contained Native `.lumora` Storage:** Portable zip containers with checksum verification, external media packing ("Collect Media"), auto-recovery, and full backward compatibility.
