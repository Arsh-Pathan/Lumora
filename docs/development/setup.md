# Development Environment Setup Guide

## Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher
- **GPU**: Graphics controller with OpenGL 3.3 / WebGL 2.0 support

## Getting Started

```bash
# Clone the repository
git clone https://github.com/lumora/lumora.git
cd lumora

# Install dependencies
npm install

# Start Vite dev server & Electron desktop application
npm run dev

# Run Vitest automated test suite
npm test

# Build production distribution bundle
npm run build
```
